# GRID 2 Mod

This release contains the GRID 2 player installers for EgoNet Revival.

Included assets:

- `EgoNet Revival - GRID 2 Installer.exe`
- `install-grid-2-mod.cmd`
- `*.sha256` checksum files
- `README.md`
- `RELEASE_NOTES.md`

Current GRID 2 support:

- RaceNet login and session tick.
- Current and previous Global Challenge events.
- Weekly Global Challenge rotation on Friday at 10:00 UTC.
- Global Challenge score submission and leaderboard display.
- Rivals list with weekly, custom, and social Rival slots.
- Weekly Rival assignments cached until the next Friday 10:00 UTC RaceNet reset.
- Multiplayer opponent learning from `DataMining.EndEvent`.
- Rival session data storage for follow-up testing.

Install flow:

1. Close GRID 2.
2. Download `EgoNet Revival - GRID 2 Installer.exe`.
3. Right-click it.
4. Run as Administrator.
5. Choose the game folder if needed, then click `Install Mod`.
6. Open GRID 2 through Steam and enter RaceNet / Rivals / Global Challenge.

GRID 2 support is still in early public testing. This is an unofficial preservation project. It is not affiliated with Codemasters, EA, Steam, or Steam Hunters.
