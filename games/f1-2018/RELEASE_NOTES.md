# F1 2018 Event Activator

This release contains the F1 2018 Event Activator for Steam/PC.

Included assets:

- `EgoNet Revival - F1 2018 Event Activator.exe`
- `activate-f1-2018-events.cmd`
- `*.sha256` checksum files
- `README.md`
- `RELEASE_NOTES.md`

Initial release:

- Reactivates the two expired 2019 weekly Events loaded by F1 2018.
- Patches both JSON timestamp fields and parsed binary timestamp values in process memory.
- Does not require the EgoNet Revival server.
- Does not edit game files, saves, Steam stats, certificates, hosts entries, or leaderboard files.

Use flow:

1. Open F1 2018 through Steam.
2. Enter the in-game Events screen.
3. Run `EgoNet Revival - F1 2018 Event Activator.exe`.
4. Return to Events or switch between current/previous Event if needed.
5. Start and finish an Event.
